# LifePlan Project Specification & AI Rules
See full rules in file:///e:/健康生活/LIFEPLAN_RULES.md

Core Constraints:
1. NEVER pre-generate fake or synthetic research/work tasks. All work tasks are user-authored memos.
2. The main overview cockpit MUST fit on a single screen without scrolling on desktop and mobile.
3. System pre-planning is strictly confined to daily diet and 3+2 workout/badminton schedule.
4. Checking off meals automatically decrements ingredient inventory.
5. All baseline data must remain pure JSON in data/*.json. All user records sync to private GitHub Gist.
6. Native Chinese typography: no spaces between Chinese characters and numbers. Single file strictly < 500 lines.
